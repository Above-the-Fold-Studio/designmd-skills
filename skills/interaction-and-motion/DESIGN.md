# Interaction and Motion

## Outcome

Feedback and transitions that make state changes understandable without slowing
the task or excluding motion-sensitive users.

## Use it when

- A direct manipulation feels disconnected from its result.
- A panel, list, or navigation transition loses spatial continuity.
- Feedback is delayed, excessive, or absent.
- Reduced-motion behavior has not been designed.

## Design approach

Start with the information gap. If the user only needs confirmation, a state
change may be enough. Use motion when origin, destination, ordering, causality,
or continuity would otherwise be unclear.

Design interruption before polish. Real users click twice, navigate away, and
receive asynchronous updates before transitions finish.
