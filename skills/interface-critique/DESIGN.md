# Interface Critique

## Outcome

A decision-ready critique that explains what matters, why it matters, and what
to improve first.

## Use it when

- Reviewing a shipped surface, prototype, screenshot, or implementation.
- Choosing which UX and visual issues deserve the next iteration.
- Reconciling subjective feedback with product goals.

## Critique is not decoration scoring

Useful critique evaluates the interface as a system: task success, information,
interaction, states, accessibility, and visual communication. Findings should
be specific enough to act on and honest about what static evidence cannot show.

## Example request

> Critique this checkout flow for comprehension, hierarchy, trust, error
> recovery, and accessibility. Give me the smallest high-impact sequence.

## Related skills

Use a foundation skill for deep work in one visual dimension. Use
design-system-audit when the unit of analysis is a reusable system rather than
one interface.
