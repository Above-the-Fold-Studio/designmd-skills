# Responsive Design

## Outcome

An interface that remains understandable and operable across space, content,
input, and user-setting changes.

## Use it when

- A page looks correct only at design-tool frame sizes.
- Navigation or data tables lose essential actions on narrow screens.
- Components depend on device labels rather than their own available space.
- Zoom, large text, or localization causes clipping and overlap.

## Design approach

Responsive design is the behavior between screenshots. Start from what must
remain visible and actionable, then let content determine when composition
changes. Prefer component-level constraints when a component can appear in
different page regions.

## Example request

> Define how this analytics view should reflow from a narrow embedded panel to
> a wide desktop while preserving comparison and export tasks.

## Related skills

Layout-and-spacing handles structural primitives. Accessible-interface checks
zoom, reflow, focus, and input access in greater depth.
