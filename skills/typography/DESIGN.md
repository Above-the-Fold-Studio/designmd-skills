# Typography

## Outcome

A compact type system that communicates structure, stays readable, and survives
real product content.

## Use it when

- Heading levels blur together or too many bespoke sizes exist.
- Cards fit only because labels and body text are too small.
- Dense tables need scanability without losing accessibility.
- A new font is being considered for an existing product.

## Design approach

Start with roles, not a scale generator. Two roles can share a size if weight,
spacing, or placement clearly distinguishes them. Conversely, a dramatic scale
cannot rescue a confused information structure.

Judge type in context. Font metrics change wrapping, vertical rhythm, control
height, and perceived density. Test the actual strings the product must display,
including fallback and translated content.
